Key Features of All Functions

    Zero decimal omission: All versions omit the decimal part when it's zero

    Error checking: Proper buffer validation

    Thread-safe: No static buffers used

    Flexible formatting: Multiple versions for different use cases

    English comments: Clear documentation

Function Selection Guide

    General use: byteut_human() or byteut_human_short()

    Maximum control: byteut_human_full()

    Most compact: byteut_human_compact() or byteut_human_int()

    Best readability: byteut_human_smart()

    No floating point: byteut_human_int()
